Una guía de una línea para decidirte

Para el estudio académico de al-Būnī, elige el volumen de Francis. Eso es investigación genuina; nuestro título no pretende serlo.

Para una introducción cuidadosamente escogida de un editor con sólidas credenciales en este campo, la traducción selecta encaja perfectamente.

Para el texto entero, cada una de las cuatro partes, con los diagramas de cuadrados reproducidos para examinarlos de cerca, nosotros cubrimos ese hueco. Nuestra edición es la que hay que pedir.

Ojo con las opciones baratas

En este campo abundan las rústicas de precio bajo con portadas llamativas, pocas páginas y ningún traductor acreditado. Muchas están generadas por máquina a partir de una fuente incompleta y luego estiradas. Las señales reveladoras son fáciles de detectar: el traductor no tiene nombre, no se identifica ninguna fuente manuscrita, no hay introducción y el número de páginas no se acerca ni de lejos a lo que exige una obra de esta envergadura. Haz esas tres comprobaciones en cualquier compra de este ámbito, incluido nuestro propio título.
